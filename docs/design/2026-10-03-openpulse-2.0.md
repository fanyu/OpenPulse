# OpenPulse 2.0 — macOS design upgrade

All eight main-window tabs and the menu bar popover now share system typography, neutral surfaces, consistent spacing, and colors for quota urgency and charts.

| Page | Result |
| --- | --- |
| Overview | Today and period metrics, trend chart, quota snapshots, model ranking, tool share, expandable project/activity/cost details |
| Quota | Responsive tool cards, calendar-day totals, account identity, both quota windows, explicit unknown and expired states |
| Activity | Native selectable session list, task/project/branch search, cached summaries, wide detail panel and compact detail presentation |
| Providers | All four integrations, account controls, credential feedback, responsive provider/model routing editor |
| Configs | File/tool search, configuration and rule tabs, native editor toolbar, Markdown preview, retained drafts and explicit save conflicts |
| Menu bar settings | Tool visibility/reordering, summary styles, Antigravity account aggregation, shared shortcut recorder |
| Settings | Grouped preferences, login-item status, language/restart feedback, notification settings, accurate cache counts and confirmed cache clearing |
| Logs | Level filters, text search, result count, newest-first rows, filtered text export |

The native sidebar groups monitoring, workspace tools and app settings, with sync status at the bottom. The default window is 1120 × 780 points and the minimum content area is 760 × 560. Narrow windows stack content and use menu filters where segmented controls do not fit.

The menu bar view is the popover opened by clicking the system menu bar icon. It leads with today's tokens, keeps each tool's quota windows visible, provides configuration shortcuts, and ends with an explicit Open OpenPulse action plus a native settings/quit menu.

Chinese and English interface copy is stored in the existing string catalog. Reset dates follow the locale and preserve AM/PM where applicable. The [menu bar preview](openpulse-2.0/menubar-dark.png) contains fictional data.

## Verification

The source was built with Xcode 27.1 for macOS Debug with signing disabled. Native visual and interaction checks use a temporary preview copy with an in-memory SwiftData container, fictional sessions/accounts, fixture configuration files, no real Keychain reads, and a URLSession protocol that rejects outbound requests. The preview harness lives outside the repository and does not ship.

Both normal light and compact dark layouts were inspected. Activity selection/search and its wide detail panel/compact sheet, configuration editing and Markdown modes, and log filtering were exercised. Configs was rechecked at 760 × 700 and the minimum content size: TOML, Markdown edit/split/preview, Diff, restored drafts, and navigation remained visible and usable. The split divider's accessibility adjustment changed its value from 50% to 54%; mouse dragging was not confirmed by the UI automation. Layout defects found during these checks were corrected and checked again.

See the [focused review report](../review/2026-10-03-openpulse-2.0-review.md) for regression coverage, fixes and remaining acceptance work. The project version remains 1.0.26; this is the 2.0 design implementation, not a release submission.
