# OpenPulse 2.0 — focused source and regression review

This pass accompanies the redesign of all eight macOS tabs and the menu bar popover. It covers the active UI, usage import/aggregation, account configuration, credential operations, OAuth callback handling and notification paths. It is not a claim that every possible bug has been found or that live integrations are accepted.

## Confirmed defects repaired

| Area | Before | Repair / evidence |
| --- | --- | --- |
| Usage snapshots | Row-count caches missed updates to existing records | Observable committed usage revision plus independent read contexts; in-memory regression updates a record without adding a row |
| Refresh lifecycle | Long-running refreshes could overlap; failed refreshes updated successful-sync time | Single refresh ownership; observable state; success-only timestamps; lifecycle regression |
| Codex sessions | Incremental cutoff omitted old conversations that were still changing | Uses SQLite updated_at when available; complete fallback scan for older schemas; temporary SQLite fixtures |
| Daily usage | Incremental imports could replace a full day with only recent totals | Whole-day Codex totals and merged persisted Claude sessions; calendar-day period boundaries |
| Session writes | One lookup per imported record and repeated unchanged field assignments | Batched ID fetches and equality guards; duplicate-batch regression |
| Antigravity sessions | Newly generated IDs duplicated the same markdown session each refresh | Directory UUID or stable namespaced path identity; temporary parser fixtures |
| Claude sessions | Missing primary directory bypassed config-directory fallback; partial chunks erased known counts | Independently scan both locations and merge only present usage fields; fixture regressions include explicit zero |
| Quota display | Missing or expired Codex values could appear as full allowance | Unknown values remain unknown, expired values wait for a fresh snapshot, weekly exhaustion constrains availability; builder/display regressions |
| Activity heatmap | Leap years beginning on Saturday needed a 54th column | Calendar-aware grid width and correct daily totals; helper regressions |
| Copilot credentials | Entered token validation could resolve a different local credential | Explicit supplied-token request; actor-owned credential I/O; no real credential/API test |
| Keychain replacement | Delete-then-add could lose working credentials on write failure | Update-first, add only when missing, preserve old entries until success, report legacy cleanup failure; injected Security-operation regressions |
| Credential deletion | Delete errors were silently ignored | Checked deletion attempts both locations and propagates status; injected deletion regressions |
| AG account metadata | Corruption became an empty list; failed saves could report success or delete usable authorization | Explicit throwing reads, atomic writes, failure-safe ordering and credential rollback; synthetic file/credential transaction regressions |
| AG refresh persistence | Raw form values broke special characters; stale JSON overwrote concurrent CLI fields | Percent encoding, current-file re-read, credential identity check and atomic write; temporary-file regressions |
| OAuth callbacks | Timeout could remain suspended indefinitely; listener fallback did not wait for bind | Single result/continuation lifecycle, cancellation/timeout handling, awaited listener start, loopback-only binding and duplicate-parameter rejection; pure callback regressions |
| Provider editing | Duplicate IDs and stale selection results could overwrite other state | Reject duplicate creation, serialize edits, guard delayed selection results, retain enabled router on failed switch |
| Config saves | External edits and stale backups could overwrite data; switching could discard drafts | Conflict check, fresh backup with permissions, atomic replacement, create-without-overwriting and guarded dirty transitions; isolated editor regressions |
| Markdown preview | Raw HTML/links could execute or fetch external content | Escaping, allowed link schemes, content policy and navigation checks; synthetic WKWebView regression |
| Configs layout | Native document fitting sizes expanded the main navigation beyond the window; nested split panes extended beneath the sidebar | Bound the page/editor to the detail viewport and use a local adjustable split; native compact/minimum text, Markdown and Diff checks |
| Notifications | Failed sends consumed the one-hour throttle; invalid or expired quota could alert | Throttle only after delivery, suppress concurrent duplicates, validate fractions/reset dates; injected async delivery regressions |
| Settings / UI | Login toggle was disconnected; restart/version/cache counts and shortcut copy were inaccurate | Native login-item API/status source, restart completion handling, bundle version, fetch counts, working cache clear, consistent shortcuts |

## Verification performed

- Static inspection of the changed sources and their callers; scoped diff checks.
- macOS Debug production build and hosted test target using Xcode 27.1, explicit local Mac destination, personal team K52WP93HZU and signing disabled.
- Hosted tests suppress startup synchronization, hook installation and live API operations. Test storage is in memory or temporary fixtures; Keychain and notifications are injected operations.
- Native preview checks with fictional data, isolated configuration files, no real Keychain access and rejected outbound network requests. All eight tabs were inspected in light/default and dark/compact windows. Activity search/selection, Markdown display and log search were exercised.
- String catalog JSON, original translation/metadata preservation, format placeholder parity, compiler extraction coverage and catalog compilation dry-run.

The final macOS Debug production build passed. The hosted test run passed all 140 tests in 22 suites. The string catalog contains 561 keys, including 293 new bilingual keys and 19 completed existing translations; all 434 nonempty extracted keys across the 36 changed Swift extraction files have English and Simplified Chinese coverage. JSON, placeholder parity, preservation and catalog compilation checks passed.

## Remaining acceptance and profiling

- Live OAuth authorization, account switching, token refresh, API quota response behavior, CloudKit/iPhone transfer, SMAppService registration and OS notification delivery were not executed. The current evidence is source, fixture tests and a synthetic native UI preview.
- Large real-history responsiveness, peak memory, filesystem event bursts, and polling/account fallback costs still need Instruments measurements. This pass removes known repeated work; it does not establish a measured production speedup.
- The Antigravity stable ID change prevents future duplicates. Existing randomly keyed cache duplicates were preserved; the app's confirmed clear-cache action can rebuild history.
- Credential JSON re-read protects edits made during an awaited refresh, but uncoordinated external writers can still race in the short read/atomic-write interval.
- Existing Codex account-store token persistence and broader secret-storage migration require a separate compatibility/security review before release.
- No release version bump, signed archive, notarization, submission, commit or push was performed.
