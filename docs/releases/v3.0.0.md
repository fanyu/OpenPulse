# OpenPulse 3.0.0

[English](#openpulse-300) · [简体中文](#中文)

OpenPulse 3.0 is a major macOS 26 design and architecture upgrade. It refreshes the brand icon and every dashboard surface, streamlines navigation into six focused tabs, adds GitHub Copilot to the menu bar, tracks Claude & Codex reset credits, and upgrades background syncing for lower overhead and greater reliability.

## What's New

- **macOS 26 Design & Refreshed Brand Identity**
  - Redesigned the app icon, menu bar icon, and sidebar with semantic navigation icons and a calmer bottom sync strip.
  - Rebuilt **Overview**, **Quota**, **Activity**, **Providers**, **Menu Bar**, and **Settings** with cohesive specular surfaces, unified responsive spacing, and full dark/light + English/Chinese polish.
  - Upgraded the **Menu Bar Popover** with aligned multi-account telemetry grids, `Pro`/`Free` Antigravity tier tags, crisp brand icons, and compact status labels.
- **Streamlined 6-Tab Architecture**
  - Consolidated navigation into two groups: **Monitor** (Overview, Quota, Activity) and **Manage** (Providers, Menu Bar, Settings).
  - Replaced the standalone Configs editor with native quick-open config file shortcuts inside **Providers** and the Menu Bar Popover.
  - Embedded diagnostic logs directly inside **Settings → Data & Diagnostics** with search, level filtering, and export.
  - Removed the obsolete Codex model router to keep multi-account management focused and dependable.
- **Claude & Codex Reset Credits**
  - Added `cedar_ember` support for **Claude Code**, distinguishing **Full Reset** and **Fable Reset** grants with expiry dates across the Menu Bar, Quota Dashboard, and Providers.
  - Added active **Codex Reset Credits** (`rate-limit-reset-credits`) filtering, expiry display, and per-window reset timestamps across single- and multi-account views.
- **Copilot Menu Bar & Interactive Menu Bar Settings**
  - Added GitHub Copilot quota percentages and a dedicated transparent template icon to the macOS menu bar.
  - Upgraded **Menu Bar Settings** with live macOS menu bar preview, drag-and-drop tool reordering (now preserved reliably across relaunches), and independent Menu Bar / Popover visibility toggles.
- **Staggered Sync Engine & Local Session Management**
  - Added per-tool configurable polling intervals with phase staggering and bounded jitter, plus silent local FSEvents refreshes that avoid flashing spinners while coding.
  - Added batch selection and safe local session deletion (moving local logs to Trash and archiving Codex threads) in **Activity**, with automatic project-filter reset when a project is cleared.

## Installation

- **macOS 26+**: Download `OpenPulse-3.0.0.zip`, extract it, and move `OpenPulse.app` to `/Applications`.
- **Signing**: Ad-hoc signed with no embedded provisioning profile (no notarization). On first launch, follow Apple's instructions in **System Settings → Privacy & Security → Open Anyway**. To use iCloud sync with the iPhone companion, build from source with your own Apple Developer team and iCloud container.

## 中文

OpenPulse 3.0 是一次面向 macOS 26 的全面设计与架构大版本升级：带来全新品牌图标与全套页面重塑、将主导航精简为六大工作区、为菜单栏补齐 Copilot 支持、完整展示 Claude 与 Codex 重置券，并重构后台同步与本地会话管理体验。

### 主要更新

- **macOS 26 视觉语言与全新品牌图标**
  - 全面更新应用图标、菜单栏图标与侧边栏导航图标体系，底部同步状态回归克制的无框细线样式。
  - 重塑 **总览、配额、活动、接入、菜单栏、设置** 六大主页面，统一响应式边距、镜面卡片质感与浅色/深色、中/英文多语言体验。
  - 升级 **菜单栏弹窗** 的多账号遥测矩阵对齐，为 Antigravity 账号增加 `Pro` / `Free` 标签，优化品牌图标与窄列日期展示。
- **精简为 6 Tab 信息架构**
  - 合并为「监控（总览 / 配额 / 活动）」与「管理（接入 / 菜单栏 / 设置）」两大分组。
  - 移除独立「配置」编辑器，改为在 **接入页** 与 **菜单栏弹窗** 中原生快捷打开本地配置文件。
  - 将诊断日志面板整合至 **设置 → 数据与诊断**，支持按级别筛选、搜索与导出。
  - 移除冗余的 Codex 模型路由模块，聚焦多账号配额监控与切换。
- **Claude 与 Codex 重置券支持**
  - 接入 Claude Code `cedar_ember` 重置券解析，精准区分 **Full Reset** 与 **Fable Reset**，并在菜单栏、配额页与接入页展示余量与过期时间。
  - 完善 Codex 重置券（`rate-limit-reset-credits`）的过期/已用过滤、最早到期排序与窗口重置时间展示（覆盖单账号与多账号）。
- **菜单栏 Copilot 支持与全新菜单栏设置**
  - 新增 GitHub Copilot 菜单栏百分比展示与专用透明模板图标。
  - 升级 **菜单栏设置** 实时预览条、拖拽排序（修复重启后自定义顺序回退的问题）以及菜单栏/弹窗独立开关。
- **交错轮询引擎与本地会话管理**
  - 支持按工具自定义后台刷新间隔，采用相位交错与有界抖动调度，并对本地 FSEvents 文件变更静默刷新，避免编码期间频繁闪动同步状态。
  - **活动页** 支持批量选择与安全删除本地会话（日志移入废纸篓、Codex 线程归档），并在删空所选项目后自动复位筛选。

### 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-3.0.0.zip`，解压后将 `OpenPulse.app` 移至 `/Applications` 目录。
- **签名状态**：公开安装包采用 ad-hoc 签名，不包含个人开发描述文件（未经过 Apple 公证）。首次打开如遇系统拦截，请在 **系统设置 → 隐私与安全性 → 仍要打开** 中放行；如需使用 iCloud 与 iPhone 伴侣端同步，请使用自己的 Apple Developer Team 从源码构建。
