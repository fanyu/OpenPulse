# OpenPulse 2.0.4

OpenPulse 2.0.4 修复了 Google Antigravity（Gemini Code Assist）订阅档位解析与 Pro 账号识别问题，并优化了全局订阅标签展示。

## What's new / 变更内容

- **修复 Antigravity 订阅档位识别**：适配 Google Code Assist 最新接口，优先解析 `paidTier` 真实会员字段（`g1-pro-tier` / `Google AI Pro` / `Google AI Ultra`），避免被固定的 `currentTier` 误判为 Free 账号。
- **优化 Pro 配额启发式规则与聚合**：解耦此前强依赖 `gemini` 分组的双窗口校验，在仅返回 `3p` 分组时基于 5 小时滚动配额准确识别 Pro 账号；`AntigravityProAggregator` 动态聚合 Pro 账号并准确呈现数量与余量。
- **全局会员状态胶囊优化**：升级 `SubscriptionTag`，为 Pro / Plus / Max / Team / Individual 等付费订阅提供半粗体与高对比质感视觉效果，弱化 Free / Starter 标签；在 Antigravity 与 Codex 账号列表中统一规范呈现。
- **Codex 订阅状态实时对齐**：`CodexAccount` 统一以 OpenAI 实时 API 返回的配额状态为准，保证界面显示准确与统一。

## Installation / 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-2.0.4.zip`；解压后将 `OpenPulse.app` 移至应用程序目录。
- **签名状态**：使用 Apple Development（Team K52WP93HZU）签名。
