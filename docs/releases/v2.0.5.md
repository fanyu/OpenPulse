# OpenPulse 2.0.5

OpenPulse 2.0.5 修复了 Google Antigravity（Gemini Code Assist）仅返回 Claude 与 GPT 模型配额的问题，恢复展示 Gemini Models 与 Gemini 4 Argon 用量，并增强了配额组解析容错能力。

## What's new / 变更内容

- **更新 Antigravity API User-Agent**：将 User-Agent 从 `antigravity/cli/1.0.13` 升级为 `antigravity/cli/1.5.8`，适配 Google Cloud Code Assist 后端的版本校验，使接口正常返回 `Gemini Models` 与 `Gemini 4 Argon` 配额组。
- **优化端点优先级**：优先使用 `daily-cloudcode-pa.googleapis.com` 作为 Antigravity 主端点（保留 `cloudcode-pa.googleapis.com` 作为回退），获取实时准确的账户配额。
- **增强 Gemini 4 Argon 解析与分组稳定性**：`window` 字段支持可选并从 `bucketId` 后缀推断，剥离窗口后缀生成独立的 `gemini-argon` 组 ID 避免与 `gemini` 冲突，并在 Pro 聚合卡片中保持稳定排序。

## Installation / 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-2.0.5.zip`；解压后将 `OpenPulse.app` 移至应用程序目录。
- **签名状态**：使用 Apple Development（Team K52WP93HZU）签名。
