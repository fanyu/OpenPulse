# OpenPulse 2.0.1

OpenPulse 2.0.1 修复了 OpenAI (Codex) 本地额度未及时刷新的问题，并移除了已下线的 Spark 试验模型额度展示。

## What's new / 变更内容

- **修复 OpenAI (Codex) 本地免接口更新时序**：优化了会话写入触发 FSEvents 时的快速刷新逻辑，确保先完成认证状态与 Keychain 凭据同步再读取账号列表，防止冷启动或凭据轮换时由于未捕获异常中断本地额度刷新。
- **适配 ChatGPT Plus 额度特性**：ChatGPT Plus 账号仅有周维度限额（无 5 小时会话窗口），已优化该场景下的额度回退与菜单栏状态指示。
- **移除 Spark 额度卡片**：从菜单栏下拉面板与配额详情页中移除已过期的 GPT-5.3-Codex-Spark 额度卡片，底层使用量持久化与合并逻辑自动清理残留的 Spark 记录。

## Installation / 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-2.0.1.zip`；解压后将 `OpenPulse.app` 移至应用程序目录。
- **签名状态**：使用 Apple Development（Team K52WP93HZU）签名。
