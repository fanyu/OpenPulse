# OpenPulse 3.0.1

[English](#openpulse-301) · [简体中文](#中文)

OpenPulse 3.0.1 is a bug-fix release that fixes in-app OAuth account login in **Providers** and improves Antigravity quota sync diagnostics and error visibility.

## What's Fixed

- **Fix OAuth Loopback Callback Server Failure**: Removed the redundant `on: port` argument when initializing `NWListener` with `parameters.requiredLocalEndpoint` in `SimpleHTTPServer`, resolving the immediate `EINVAL` error when adding OpenAI (Codex) or Google (Antigravity) accounts in **Providers**. Also fixed the HTTP response header terminator (`\r\n\r\n`) returned to browsers after OAuth callback.
- **Surface Per-Account Antigravity Quota Errors**: Parse structured Google API error messages and verification URLs (such as `HTTP 403: Verify your account to continue.`), persist them to diagnostics, and display them directly on the account card instead of leaving accounts stuck on *"Awaiting initial quota sync"*.
- **Immediate Post-Login Sync & Complete OAuth Scopes**: Share a single `AntigravityAccountService` instance between `AppStore` and `DataSyncService`, trigger an immediate single-account quota refresh right after Google OAuth completes, request the full Antigravity OAuth scopes (`cclog` and `experimentsandconfigs`), and fall back across `loadCodeAssist` endpoints when the first endpoint returns empty metadata.

## Installation

- **macOS 26+**: Download `OpenPulse-3.0.1.zip`, extract it, and move `OpenPulse.app` to `/Applications`.
- **Signing**: Ad-hoc signed with no embedded provisioning profile (no notarization). On first launch, follow Apple's instructions in **System Settings → Privacy & Security → Open Anyway**. To use iCloud sync with the iPhone companion, build from source with your own Apple Developer team and iCloud container.

## 中文

OpenPulse 3.0.1 修复了 **接入（Providers）** 页面添加账号时立即报错的问题，并优化了 Antigravity 配额同步诊断与错误展示。

### 修复内容

- **修复 OAuth 本地回调服务启动报错**：移除 `SimpleHTTPServer` 初始化 `NWListener` 时与 `parameters.requiredLocalEndpoint` 冲突的重复 `on: port` 参数，解决在 **接入** 页面点击添加 OpenAI（Codex）或 Google（Antigravity）账号直接报 `Invalid argument` 的问题；同时补全 HTTP 回调响应头的标准 `\r\n\r\n` 换行分隔符。
- **展示 Antigravity 单账号配额错误**：解析 Google API 返回的结构化错误信息与验证链接（如 `HTTP 403: Verify your account to continue.`），写入诊断日志并直接展示在对应账号卡片中，避免拉取失败时一直停留在「等待首次额度同步」。
- **优化登录后立即刷新与 OAuth 权限范围**：在 `AppStore` 与 `DataSyncService` 间共享同一 `AntigravityAccountService` 实例，登录完成后立即针对新账号触发单账号配额刷新，补全 Antigravity OAuth 所需的 `cclog` 与 `experimentsandconfigs` scope，并在 `loadCodeAssist` 返回空项目/等级时继续尝试备用端点。

### 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-3.0.1.zip`，解压后将 `OpenPulse.app` 移至 `/Applications` 目录。
- **签名状态**：公开安装包采用 ad-hoc 签名，不包含个人开发描述文件（未经过 Apple 公证）。首次打开如遇系统拦截，请在 **系统设置 → 隐私与安全性 → 仍要打开** 中放行；如需使用 iCloud 与 iPhone 伴侣端同步，请使用自己的 Apple Developer Team 从源码构建。
