# OpenPulse 2.0.3

OpenPulse 2.0.3 强化了钥匙串（Keychain）在已签名应用环境下的兼容性与隔离机制，防止旧版凭据清理时误影响 Data Protection 存储。

## What's new / 变更内容

- **显式指定传统钥匙串标记**：在回退查询、传统项清理、检索以及删除流程中，显式传入 `kSecUseDataProtectionKeychain: false`，避免已签名应用在省略该键时被系统默认路由至 Data Protection Keychain，确保旧凭据安全平滑迁移与清理。

## Installation / 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-2.0.3.zip`；解压后将 `OpenPulse.app` 移至应用程序目录。
- **签名状态**：使用 Apple Development（Team K52WP93HZU）签名。
