# OpenPulse 3.0.2

[English](#openpulse-302) · [简体中文](#中文)

OpenPulse 3.0.2 adds manual drag-and-drop and automatic quota-based sorting for multi-account tools in the Menu Bar popover and Menu Bar settings.

## What's New

- **Multi-Account Sorting in Menu Bar Popover**: Added a compact 3-mode sort switcher (**Manual**, **Remaining Quota High → Low**, **Remaining Quota Low → High**) on multi-account **Codex** and **Antigravity** cards, plus direct drag-and-drop reordering of account rows right inside the popover.
- **Multi-Account Sorting in Menu Bar Settings**: Added a dedicated **Multi-Account Order** section to manage sort modes, drag handles, and move-up/move-down controls per tool with live remaining-quota badges.
- **Deterministic Quota Ranking**: Auto-sorting ranks accounts by effective remaining quota (treating weekly-exhausted accounts as `0%` and placing unknown or expired quota observations last) while preserving hidden account order in manual mode.

## Installation

- **macOS 26+**: Download `OpenPulse-3.0.2.zip`, extract it, and move `OpenPulse.app` to `/Applications`.
- **Signing**: Ad-hoc signed with no embedded provisioning profile (no notarization). On first launch, follow Apple's instructions in **System Settings → Privacy & Security → Open Anyway**. To use iCloud sync with the iPhone companion, build from source with your own Apple Developer team and iCloud container.

## 中文

OpenPulse 3.0.2 为菜单栏下拉面板与菜单栏设置新增了多账号手动拖拽排序与按剩余额度自动排序功能。

### 主要更新

- **菜单栏下拉面板多账号排序**：在多账号 **Codex** 与 **Antigravity** 卡片标题栏新增三态排序切换胶囊（**手动** / **额度多 → 少** / **额度少 → 多**），并支持在下拉面板中直接拖拽账号行调整顺序（自动排序下拖拽会自动保存并切为手动顺序）。
- **菜单栏设置新增「多账号排序」面板**：分别配置 Codex 与 Antigravity 的排序模式，支持拖拽手柄与悬停上移/下移按钮，并实时展示用于排序的主剩余额度百分比。
- **可靠的额度排序规则**：自动排序按有效剩余额度排列（周额度耗尽视为 `0%`，未知或过期额度始终排在末尾），手动模式保留隐藏账号位置并将新增账号追加至末尾。

### 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-3.0.2.zip`，解压后将 `OpenPulse.app` 移至 `/Applications` 目录。
- **签名状态**：公开安装包采用 ad-hoc 签名，不包含个人开发描述文件（未经过 Apple 公证）。首次打开如遇系统拦截，请在 **系统设置 → 隐私与安全性 → 仍要打开** 中放行；如需使用 iCloud 与 iPhone 伴侣端同步，请使用自己的 Apple Developer Team 从源码构建。
