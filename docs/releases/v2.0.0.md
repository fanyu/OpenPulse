# OpenPulse 2.0.0

OpenPulse 2.0 brings a redesigned native macOS dashboard and menu bar popover, with clearer quota states, more reliable usage imports, and safer account/configuration operations.

## What's new

- Redesigned **Overview, Quota, Activity, Menu Bar, Providers, Configs, Settings, and Logs**, with layouts for wide and compact windows and English/Simplified Chinese interface coverage.
- Overview brings token trends, quota summaries, activity patterns, and model/project analysis together. Activity supports full-history search, session details, background data processing, and incremental row rendering.
- Refreshed menu bar cards and settings make account quotas, tool order, visibility, display style, and shortcuts easier to find.

## Correctness and reliability

- Usage views now observe edits to existing records. Daily totals preserve complete-day usage, changing older Codex conversations remain eligible for import, and Antigravity sessions use stable identities.
- Refreshes share ownership, successful timestamps advance only after accepted persistence, and file events received during a refresh trigger bounded catch-up work.
- Missing, expired, or failed quota observations remain unknown or stale. Codex smart switching requires recent successful data and confirmed current-account exhaustion.
- Codex account JSON now stores metadata and quota observations; saved authorization lives in Keychain. Legacy migration verifies credential read-back before replacing the old file and preserves it on failure.
- Account saves, credential replacement, OAuth callbacks, provider edits, and configuration saves handle failure paths more carefully. Config edits detect external changes and Markdown previews restrict active content.
- Desktop snapshots keep session and weekly windows separate and preserve observation times. iPhone state retains fetch errors, rejects older snapshots, and handles expired windows consistently.
- Notification throttling follows successful delivery; launch-at-login status, cache controls, and version/shortcut text use their active sources.

## Installation and limits

- **macOS 26+**: the release asset is `OpenPulse-2.0.0.zip`; extract it and move `OpenPulse.app` to Applications.
- **Signing and notarization status:** pending final package verification.
- The **iOS 26+** companion remains a separate source target. It displays Codex/Claude snapshots and requires matching iCloud access; it is not included in the macOS ZIP.
- Inactive Codex accounts do not yet automatically renew expired authorization. Reauthenticate or import fresh authorization when needed.
- Existing Antigravity cache duplicates from older randomly generated IDs are preserved. The confirmed clear-cache action can rebuild local history.

The [initial review](../review/2026-10-03-openpulse-2.0-review.md) and [follow-up review](../review/2026-10-03-openpulse-2.0-follow-up.md) document compilation, fixture tests, native previews, and synthetic Activity profiling. Those checks do not establish live OAuth, real Keychain migration, API behavior, account restart, iCloud transfer, login registration, or OS notification delivery. Synthetic performance results are scoped to their fixtures; no general performance percentage is claimed.

## 中文

OpenPulse 2.0 重新设计了原生 macOS 主面板和菜单栏弹窗，改善额度状态展示、用量导入，以及账号和配置操作的可靠性。

### 新界面

- 重做 **总览、配额、活动、菜单栏、接入、配置、设置、日志** 八个页面，适配宽屏与紧凑窗口，并补全英文和简体中文界面。
- 总览集中展示 Token 趋势、额度摘要、活动规律和模型/项目分析。活动页支持全部历史搜索、会话详情、后台数据处理和分批渲染。
- 更新菜单栏卡片与设置，让账号额度、工具顺序、显隐、样式和快捷键更易查找。

### 修复与可靠性

- 用量界面能响应已有记录的修改；每日汇总保留完整数据，旧 Codex 会话发生变化后仍可导入，Antigravity 会话使用稳定标识。
- 统一刷新占用状态，仅在数据成功保存后更新时间；刷新期间收到的文件事件会触发后续补充处理。
- 缺失、过期或获取失败的额度保留未知/过期状态。Codex 智能切换需有近期成功数据并确认当前账号额度耗尽。
- Codex 账号 JSON 改为保存元数据与额度缓存，授权保存在 Keychain。旧格式迁移先验证凭据回读，失败时保留旧文件。
- 完善账号保存、凭据替换、OAuth 回调、Provider 编辑和配置保存的失败处理；配置编辑检测外部修改，Markdown 预览限制活动内容。
- Mac 快照分别保留 5h 与每周窗口及原始观测时间；iPhone 保留获取错误，拒绝旧快照，并正确处理过期窗口。
- 通知成功送达后才计入频率限制；修复开机启动状态、缓存操作，以及版本和快捷键文案。

### 安装与限制

- **macOS 26+**：发布附件为 `OpenPulse-2.0.0.zip`；解压后将 `OpenPulse.app` 移至应用程序。
- **签名与公证状态：** 等待最终安装包验证。
- **iOS 26+** 伴侣仍为独立源码目标，展示 Codex / Claude 快照，需要相同 iCloud 访问权限，不包含在 macOS ZIP 中。
- 非当前 Codex 账号暂不自动续期过期授权，需要时请重新登录或导入最新授权。
- 保留旧版随机标识产生的 Antigravity 缓存重复项；可通过已确认的清除缓存操作重建本地历史。
