# OpenPulse 2.0.2

OpenPulse 2.0.2 修复了 Google Cloud Code Assist (Antigravity) 菜单栏额度显示为 `--%` 的问题，并强化了状态栏配额多级安全回退机制。

## What's new / 变更内容

- **修复 Antigravity 接口端点优先级**：将生产环境正式端点 `cloudcode-pa.googleapis.com` 调整为第一优先级，解决 Google 预发布端点缺少 `Gemini Models` 配额组导致状态栏解析为空的问题，恢复正常显示 Gemini 与 3P 模型的 5 小时及周维度额度。
- **状态栏多级安全回退**：菜单栏状态栏图标额度计算引入多级降级逻辑（Gemini 5h ➔ 3P 5h ➔ Gemini 7d ➔ 3P 7d），在单项配额窗口或模型组缺失时自适应展示有效额度数字，杜绝异常显示 `--%`。
- **隐藏账号过滤**：状态栏平均额度计算严格遵守用户在偏好设置中配置的隐藏账号（`ag.hiddenAccountEmails`），避免未启用或过期的账号影响状态栏均值。
- **SwiftData 聚合数据兜底**：持久化配额聚合逻辑增加对非 Gemini 首选组的回退支持，保障聚合卡片始终具备有效的数据摘要。

## Installation / 安装说明

- **macOS 26+**：发布附件为 `OpenPulse-2.0.2.zip`；解压后将 `OpenPulse.app` 移至应用程序目录。
- **签名状态**：使用 Apple Development（Team K52WP93HZU）签名。
